## Task Type: Reference-to-Video (R2V / Omni) for Google Flow Veo 3

This is a Reference-to-Video generation task utilizing character and visual asset references.

Guidelines:
- Faithfully incorporate the identity, physical features, costume, and color palette of the referenced character or object.
- Integrate the referenced assets seamlessly into a new dynamic scene environment.
- Write camera kinematics as an independent, dedicated sentence.
- If dialogue is included, format strictly as: Character says: "..." (no subtitles)
- Conclude with Audio:, SFX:, Music:, and Negative: lines.
